-----------clone command----
to list all file in current directory-dir /a
to clone project -> git clone <link>
to find hidden files -> dir /a:h

------------status command------
tells status of our code
to check status of project-> git status

after modifying anything 2 step process
1.add
2.commit
'u' infornt of any file means-untracked file
'm' means modified 

git have 4 types of status
1. untracked -new files that git doesn't yet track
2.modified-changed
3.staged-file us ready to be committed (files added but not committed)
4.unmodified-changed


---------------add & commit-----------------

1.add-adds new or changed files in your working directory to the git staging area.

git add <-file name->

to enter all the files -> git add.

2.commit -it is the record of changes

git commit -m "some message"


--------------push command----------------
to update all the things happened in local system to github we use push.i.e upload local repo content to remote repo

git push origin main
origin -repo in github is named as origin(can be anything)
main-is the branch on which we are making changes

---------------init command------
init -used to create a new git repo

git init-> to initialize git and use git we use this command

to add the the project to git hub
1.create repo in github
2. git remote add origin <-link> ->th the above created repo link to make it origin
3.git remote -v -> to verify remote
4.git branch ->to check branch ( mater branch is the default branch)
5.now we have to create main branch and doo changes there or we can also change the name of master to main
rename master as main
git branch -M main ->to rename branch
6.now again do ->git push origin main
we can also use-> git push -u origin main
this is done to set upstream (it reduces the task of writing origin main often) . now we can just write -> git push

1.github repo
